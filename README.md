# 听到涛声 · 逐句学习网页版

轻量网页版本，保留全书 2,640 个原文行的日文、中文参考、词语解释、假名、罗马音、语法笔记、五十音表和随机选择题。

**本仓库不包含日语朗读、中文配音、语法讲解音频和插图，也不需要下载或运行 AI 模型。** 朗读、循环与插图入口在这个版本中隐藏。原有本地完整版不受影响。

## Windows 打开方法

1. 安装 [Node.js](https://nodejs.org/)（20 或更高版本）。已经安装的电脑可跳过。
2. 点击 GitHub 的 **Code → Download ZIP**，完整解压文件夹；保留 `umi-reader` 子目录。
3. 双击根目录的 **启动听到涛声网页版.cmd**。

网页地址：[http://127.0.0.1:4173/](http://127.0.0.1:4173/)。启动器会在后台运行服务，并自动打开浏览器。阅读不需要运行 `npm install`。

用完可双击 **停止听到涛声网页版.cmd**。电脑重启后再次启动即可；未设置开机自启。

如果电脑已经运行之前的完整版，两者默认都使用 4173 端口。可先关闭之前的服务，或用 PowerShell 为这个版本指定另一个端口：

```powershell
.\umi-reader\scripts\start-web.ps1 -Port 4175
```

仅启动、不打开浏览器：

```powershell
.\umi-reader\scripts\start-web.ps1 -NoBrowser
```

macOS、Linux 或终端启动：在仓库根目录运行 `npm start`，再打开上述地址。按 Ctrl+C 停止。

## 手机浏览器

电脑与手机连接同一 Wi-Fi，电脑保持开机。在电脑网页里点 **手机打开**，或在设置里查看手机访问地址，用手机浏览器打开该局域网网址。如系统防火墙询问网络访问权限，请按自己所在网络选择；程序不会自动修改防火墙。

阅读位置保存在各自浏览器中，不会自动跨设备同步。可通过设置里的 **导出进度 / 导入进度** 转移学习进度。没有账号服务，也没有开启 GitHub Pages 公网托管。

## 文件位置

- `启动听到涛声网页版.cmd`、`停止听到涛声网页版.cmd`：Windows 入口。
- `umi-reader/scripts/start-web.ps1`、`stop-web.ps1`、`serve.mjs`：后台启动、停止与本地网页服务。
- `umi-reader/dist/`：可直接运行的网页、正文学习数据及样式。
- `umi-reader/dist/media-mode.js`：这个版本的无媒体模式。
- `.gitignore`：排除音频、插图、模型、缓存、密钥和安装包。

服务只提供阅读资源和局域网访问地址，不提供上传或修改电脑文件的接口。默认监听 `0.0.0.0:4173`，可通过 `UMI_HOST`、`UMI_PORT` 指定其他地址和端口。

## 开发检查

运行网页不需要依赖安装；只有开发检查才需要：

```sh
npm ci
npm run check
```

检查覆盖原文与学习分组一致性、全书随机选择题、无媒体页面的基本操作。
